# 终端界面说明

## 布局

主区域顺序为：

```text
Transcript
Editor
Widget Area
Status Bar
```

可选 Header 只显示低干扰状态。Transcript 无外框并占据主要空间，下方保留少量视觉间距。Editor 是默认唯一带边框的区域，不增加内部留白。Widget Area 和 Status Bar 无外框、无额外内边距；没有内容时 Widget Area 收缩为零高度。

背景色只用于连续完整区域或完整的选中行，不用于单个词、令牌或状态标签。低颜色终端仍应通过前景色、加粗、下划线、图标和左侧标记表达状态。

## 输入

- Enter：提交普通提示；有选中的斜杠补全项时直接执行。
- Tab：接受斜杠补全但不执行。
- Ctrl+Enter：向活动运行插入插话消息。
- Enter：活动运行中将新消息排队，等待当前轮结束后继续。
- Esc：取消活动运行。
- Ctrl+C：优先取消活动运行；没有活动运行时清空输入，空输入时退出。

## 常用命令

- `/new`：创建新会话。
- `/resume`：恢复会话。
- `/name`、`/rename`：设置会话名称。
- `/compact`：执行确定性本地压缩。
- `/memory`：查看本地记忆状态。
- `/reload`：重新加载受信任用户插件并安排 MCP 刷新，下一次运行生效；活动运行不会热替换。
- `/status`：显示当前运行或首次空闲配置，并包含 MCP 配置、健康状态、工具目录哈希和 reload 状态。
- `/trust`：设置当前工作区 Trust。
- `/help`：显示帮助。

TUI 只负责输入和呈现；模型调用、工具执行、会话保存和 RPC 逻辑由共享的应用层完成。
