# Agent 应用示例

这些示例是给 `nju-agent` 练习工具调用、验证和插件开发的独立题目。每个目录都包含任务说明；运行 agent 时请明确指定目标目录。

## 题目

- `bug-fix/`：修复一个已有项目中的 bug，并运行测试证明修复有效。
- `feature-development/`：在已有项目中开发一个新功能，补充测试并保持现有行为。
- `self-hosting-plugin/`：为 `nju-agent` 开发一个插件，使用标准插件接口注册工具；目标示例是 `nju-mcp-adaptor`。

建议统一要求 agent：先阅读 README 和源码，修改前说明计划，完成后运行项目测试，不修改题目测试来绕过失败。
